At the present stage, more than 50% of the File Integrity Tester has been completed. The major

with a previously stored trusted baseline.
i. Design / Model Developed
The proposed File Integrity Tester follows a baseline-based integrity verification model. The
system begins by allowing the user to select the files or directories that need to be monitored.
During the initial scan, the system calculates a cryptographic hash value for each selected file
and stores the hash along with relevant file information such as file path, file size, and
modification time. This information forms the trusted baseline.
During subsequent scans, the system again reads the selected files and calculates their current
hash values. The comparison module compares the newly calculated values with the
corresponding baseline values. If the hash values are identical, the file is considered unchanged.
If the hash value differs, the file is classified as modified. Files that are present in the current
scan but not in the baseline are identified as added, while files present in the baseline but missing
during the current scan are identified as deleted.
